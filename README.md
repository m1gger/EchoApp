============================================================
  Echo Server / Client — Лабораторная работа №1
============================================================

Описание
--------
Многоклиентный TCP эхо-сервер на C# (.NET 8).
Каждое сообщение, отправленное любым клиентом, рассылается
всем подключённым клиентам (включая отправителя).
Сервер хранит очередь последних 100 сообщений и отправляет
её новым (или медленным) клиентам.

Структура проекта
-----------------
src/EchoApp/
  Program.cs              — точка входа, разбор аргументов
  Server/
    EchoServer.cs         — TCP-сервер, управление клиентами
    ClientHandler.cs      — обработчик одного подключения
  Client/
    EchoClient.cs         — TCP-клиент, лог входящих сообщений

Сборка
------
cd src/EchoApp
dotnet build -c Release

Запуск из папки bin (уже собранные файлы)
------------------------------------------
Запуск сервера:
  EchoApp.exe server [port]
  Пример: EchoApp.exe server 5000

Запуск клиента:
  EchoApp.exe client [host] [port] [logfile]
  Пример: EchoApp.exe client 127.0.0.1 5000 client.log

Управление
----------
- После запуска клиента введите текст и нажмите Enter для отправки.
- Все входящие сообщения выводятся на экран с префиксом [Echo].
- Все входящие сообщения записываются в лог-файл (по умолчанию client.log).
- Для завершения работы клиента нажмите Ctrl+C или закройте stdin (Ctrl+Z в Windows).
- Для завершения сервера нажмите Ctrl+C.

Параметры по умолчанию
-----------------------
  port    = 5000
  host    = 127.0.0.1
  logfile = client.log

Пример сессии (два окна терминала)
------------------------------------
Окно 1 (сервер):
  > EchoApp.exe server 5000
  [Server] Listening on port 5000. Press Ctrl+C to stop.
  [Server] Client connected: 127.0.0.1:50001
  [Server] Client connected: 127.0.0.1:50002

Окно 2 (клиент 1):
  > EchoApp.exe client 127.0.0.1 5000 client1.log
  [Client] Connected to 127.0.0.1:5000.
  Hello!
  [Echo] Hello!

Окно 3 (клиент 2):
  > EchoApp.exe client 127.0.0.1 5000 client2.log
  [Client] Connected to 127.0.0.1:5000.
  [Echo] Hello!      ← сообщение от клиента 1
